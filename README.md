# ASoVtetra_version0.1.0
## Version
現在のバージョン： v0.1.0

## 本バージョンの機能
-  PNG画像を、読み込み、Windows のデスクトップの画面に描画します。
（ビットの深さ：３２。推奨）

- 普通ウインドウの移動・サイズ変更し、Ｆ１キーで、固定すると、デスクトップの画面の最前面（Top）で、描画されます。
  - 描画は、Direct2Dのレイヤード描画に切り替わっています。
  - 本プログラムを選択していても、描画している画像を、クリックしても、背面にあるウインドウ操作になります。

## 本バージョンの利用するポイント（例）
- デスクトップ上をキャプチャするときに、オリジナルロゴなどを常に、最前面に固定し、かつ、作業には影響しないように利用できる。

- OBSの画面にて、任意の位置への移動と固定が自在に。

- デスクトップ作業中に、モチベーションあがるキャラクター画像が、透明度をつけて、固定描画することで、ジャマにならずに、あななたの作業のモチベーションを、支援します。

## 動作環境 & 起動方法
- 推奨環境
 - Windows 11 64bit (x64)
 - Windows 11 32bit (x86)

- 起動方法
 - それぞれ、対応する、Zipファイルをダウンロードし、解凍して、フォルダの中に在る、”ASoVtetra_version0.1.0.exe” を起動。
